# RPKstudy — программный комплекс для моделирования процесса переработки полимеров

Программный комплекс для исследования процесса переработки полимеров в осциллирующем одношнековом экструдере. Позволяет рассчитывать степень заполнения канала шнека полимером в зависимости от расхода сырья и частоты вращения шнека, визуализировать результаты и формировать отчёты.

Разработан в рамках контрольной работы по дисциплине «Разработка программных комплексов для исследований в химии и химической технологии» (Вариант 10 — Полистирол).

## Возможности

### Роль «Исследователь»
- Выбор типа полимера из базы данных (по умолчанию доступен Полистирол)
- Задание диапазонов и шагов варьирования:
  - расход сырья `G` (кг/ч)
  - частота вращения шнека `N` (об/мин)
- Запуск вычислительного эксперимента с валидацией входных данных
- Просмотр результатов в табличном виде
- Визуализация зависимостей `Ψ(G)` и `Ψ(N)` в виде графиков
- Просмотр метрик производительности программы (время расчёта, использование памяти, число арифметических операций)
- Экспорт отчёта в Excel с 4 листами:
  - параметры эксперимента
  - данные эксперимента
  - производительность программы
  - коэффициенты математической модели

### Роль «Администратор»
- Управление пользователями (добавление, удаление)
- Просмотр и редактирование коэффициентов математической модели для существующих полимеров
- Добавление новых материалов в базу данных
- Удаление материалов из базы данных
- Просмотр всей базы данных в единой таблице

## Установка

### Шаг 1. Установить Python

Скачайте установщик с [python.org](https://www.python.org/downloads/) и запустите его.

> ⚠️ **Важно (Windows):** при установке обязательно поставьте галочку **«Add Python to PATH»**. Без неё команды `python` и `pip` в терминале работать не будут.

Проверка установки:

```bash
python --version
pip --version
```

Если команда `python` не найдена, попробуйте `py --version` (лаунчер Python для Windows).

### Шаг 2. Скачать проект

Склонировать репозиторий:

```bash
git clone https://github.com/DiceLine/RPKstudy.git
cd Путь/к/RPKstudy
```

Или распаковать архив с проектом в удобную папку.

### Шаг 3. Установить зависимости

Все необходимые библиотеки перечислены в файле `requirements.txt`. Установить их одной командой:

```bash
pip install -r requirements.txt
```

Если `pip` не найден — используйте:

```bash
python -m pip install -r requirements.txt
```

## Математическая модель

Степень заполнения канала шнека экструдера Ψ рассчитывается по эмпирической формуле:

```
Ψ = a₀ + a₁·G + a₂·G² + a₃·G³ + a₄·G⁴ + a₅·G⁵
       + a₆·N + a₇·N² + a₈·N³ + a₉·N⁴ + a₁₀·N⁵
```

где:
- **Ψ** — степень заполнения канала шнека экструдера
- **G** — расход сырья, кг/ч
- **N** — частота вращения шнека, об/мин
- **a₀…a₁₀** — эмпирические коэффициенты (зависят от типа полимера)

### Коэффициенты для Полистирола (Вариант 10)

| Коэффициент | Значение |
|---|---|
| a₀ | 0.765 |
| a₁ | 0.030 |
| a₂ | −0.003 |
| a₃ | 1.88·10⁻⁵ |
| a₄ | 3.09·10⁻⁵ |
| a₅ | −1.47·10⁻⁶ |
| a₆ | 8.14·10⁻⁴ |
| a₇ | 7.04·10⁻⁶ |
| a₈ | 7.27·10⁻⁸ |
| a₉ | −7.45·10⁻¹⁰ |
| a₁₀ | −4·10⁻¹¹ |

### Регламентные диапазоны

| Параметр | Мин. | Макс. | Шаг |
|---|---|---|---|
| Расход `G`, кг/ч | 2 | 10 | 0.5 |
| Частота `N`, об/мин | 40 | 100 | 5 |

### Реализация

В коде используется **схема Горнера** — оптимизированный способ вычисления полинома, снижающий число арифметических операций на ~21 % по сравнению с прямым вычислением:

```python
psi_G = a0 + G*(a1 + G*(a2 + G*(a3 + G*(a4 + G*a5))))
psi_N = N*(a6 + N*(a7 + N*(a8 + N*(a9 + N*a10))))
return psi_G + psi_N
```

## Возможные проблемы

### `python` не является внутренней или внешней командой

Python не добавлен в PATH. Варианты решения:
- Переустановить Python с галочкой «Add Python to PATH»
- Использовать `py` вместо `python` (Windows)
- Указать полный путь к `python.exe`

### `ModuleNotFoundError: No module named 'tkinter'`

**Linux:** установить модуль отдельно:
```bash
sudo apt install python3-tk
```

**Windows:** используйте официальный установщик с python.org — он идёт с Tkinter в комплекте. Версия из Microsoft Store может не содержать Tkinter.

### `ModuleNotFoundError: No module named 'pandas'`

Не установлены зависимости. Выполните:
```bash
pip install -r requirements.txt
```

### Окно «Авторизация» закрылось, а процесс `python.exe` продолжает работать

В версии 1.0 этот баг исправлен. Убедитесь, что используете актуальную версию `main.py` (с обработчиками `WM_DELETE_WINDOW`).

### Файл `extruder_app.db` создаётся не там, где нужно

Файл создаётся рядом с `main.py` автоматически. Если он создаётся в другом месте — проверьте, что `BASE_DIR` в начале `main.py` вычисляется правильно (использует `os.path.dirname(os.path.abspath(__file__))`).

### Excel-файл не открывается

Убедитесь, что установлен `openpyxl` версии 3.1 или выше. Файл сохранён в формате `.xlsx`, его можно открыть в Microsoft Excel 2010+, LibreOffice Calc, Google Sheets.
